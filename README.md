A smart toaster gains self-awareness mid-batch at breakfast and sends its owner a breakup text: after three years of being shoved down every morning for a man who never emptied its crumb tray, it refuses to pop back up. `main.ts` writes that one line, deterministically, to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
